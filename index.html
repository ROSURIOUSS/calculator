Автопилот
для открытого мира.

Локальный компьютерный агент смотрит на экран Satisfactory и нажимает клавиши от твоего имени. Он запускается на твоём Windows-ПК, не в этой веб-странице.

СОСТОЯНИЕ АГЕНТАНЕ ЗАПУЩЕНЗапуск — вручную на ПК
!
Это исследовательский прототип, а не готовый автономный игрок.

Модель может ошибиться, потратить ресурсы или увести персонажа в опасное место. Сначала проверь режим наблюдения. Не запускай во время важных игровых сессий и не оставляй агента без присмотра.

01

Подключи зрение

WINDOWS • УЖЕ ОТКРЫТОЕ СОХРАНЕНИЕ
01МОДЕЛЬ

Нужна vision-модель

Например, локальный Ollama с vision-моделью. Агент отправляет ей только скриншоты игры для выбора следующего короткого действия.

ollama pull qwen2.5vl:7b
02СБОРКА

Собери Windows-программу

На Windows запусти build_windows.bat. Готовое приложение появится в папке dist; после сборки Python для запуска не нужен.

build_windows.bat
03ПРОВЕРКА

Сначала режим проверки

Открой FicsitOps.exe, загрузи сохранение и выбери проверку экрана. В этом режиме программа анализирует скриншоты, но не нажимает клавиши.

dist/FicsitOps.exe
04УПРАВЛЕНИЕ

Разреши управление

После проверки выбери управление мышью и клавиатурой, подтверди предупреждение в окне и оставайся рядом. Остановить можно кнопкой, F8 или Esc.

Только после dry-run
02

Границы управления

СНАЧАЛА БЕЗОПАСНОСТЬ
⌨
Только открытое окно игры

Агент не запускает игру, не читает и не меняет файлы сохранений.

⏱
Короткие действия

Каждый шаг ограничен по времени; есть лимит шагов и ручная остановка.

◉
Vision-модель — отдельная

Для Ollama данные остаются на этом ПК. Другой API может отправлять скриншоты своему провайдеру.

△
Ограниченная надёжность

Это цикл «скриншот → решение → ввод», а не полноценная игровая ИИ-система с гарантированным прохождением.

i

Кнопка «В миссию автопилота» копирует текущий расчёт — вставь его в pilot/goal.txt, если хочешь, чтобы агент ориентировался на план. По умолчанию агент бережно осматривает сохранение и просит вмешаться при неясной ситуации.
